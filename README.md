# Ecommerce_Return_Rate_Investigation
## Project Overview

This project analyzes an e-commerce returns dataset to identify the key factors influencing product returns. The analysis focuses on return reasons, product categories, customer behavior, discounts, shipping methods, and return patterns to generate actionable business insights and recommendations.

---

## Objective

The main objectives of this project are:

- Identify factors contributing to product returns.
- Determine high-risk product categories.
- Analyze the impact of discounts and shipping methods on returns.
- Perform statistical testing to evaluate return-related hypotheses.
- Generate business recommendations to reduce return rates and improve customer satisfaction.

---

## Key Findings

- Defective products were the leading cause of returns.
- Wrong-item deliveries significantly contributed to returns.
- Clothing, Books, and Electronics showed the highest return volumes.
- Higher discounts were associated with increased return activity.
- Delayed delivery did not significantly affect return probability.

---

## Business Recommendations

- Improve product quality control.
- Reduce wrong-item shipments through better order verification.
- Enhance product descriptions and images.
- Monitor high-return categories.
- Collect customer feedback to identify recurring issues.
